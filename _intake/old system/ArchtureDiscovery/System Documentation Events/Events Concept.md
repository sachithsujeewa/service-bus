# Events Concept

# What are events and what can it be used for?

An event is a record of an activity in Rambase. When a value is changed, an event is created that describes this change.

Events can be used to get a history flow of a certain type of events. By monitoring the events that are created it is possible to have a live information flow about a system.

Look at the [WebHook implementation](https://rambase.atlassian.net/wiki/spaces/API/pages/21954614) that make use of the Rambase event concept.
