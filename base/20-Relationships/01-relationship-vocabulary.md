# Relationship Vocabulary

Use this controlled vocabulary for typed relationships.

## Generic relationships

```text
requires
uses
includes
belongs_to
part_of
depends_on
supports
explains
validates
affects
produces
consumes
derived_from
compared_with
replaces
deprecated_by
related_to
```

```text

```

## Standard format

```markdown
- [[Source]] --relation--> [[Target]]
```

## Example

```markdown
- [[Concept A]] --requires--> [[Concept B]]
```
