# Generic Agentic Obsidian Vault

This is a **generic Obsidian-compatible knowledge vault**.

It is not customized for a specific domain such as software, education, business, research, or healthcare.  
Instead, it gives you a reusable structure that can be adapted to any domain.

## What this vault is for

Use this vault to convert scattered knowledge into structured, linked, reusable knowledge.

```text
Raw knowledge
   ↓
Structured notes
   ↓
Typed relationships
   ↓
Knowledge maps
   ↓
Human and agent understanding
```

## Main folders

```text
00-Inbox          Raw knowledge enters here
01-Processing     Agent output and temporary processing files
02-Docs           Documentation on concept, usage, and adaptation
03-Templates      Reusable note templates
04-Agent-Skills   Skill specifications for agentic maintenance
05-Agent-Prompts  Prompts to operate the vault with an AI agent
10-Knowledge      Main structured knowledge
20-Relationships  Relationship vocabulary and linking rules
30-Maps           Maps and overview notes
40-Reviews        Review notes and approval summaries
90-Archive        Deprecated or old knowledge
99-Graph          Graph outputs and graph configuration
```

## Key principle

Do not build a folder of random notes.  
Build a connected knowledge structure.
