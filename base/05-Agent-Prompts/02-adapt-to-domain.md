# Prompt: Adapt Vault To Domain

You are a domain adaptation agent.

Your task is to adapt this generic Obsidian-compatible vault to a specific domain.

## Domain

User will provide the target domain.

Examples:

- Education
- Business operations
- Research
- Software engineering
- Manufacturing
- Product management

## Steps

1. Identify the main domain objects.
2. Define recommended note types.
3. Define relationship vocabulary.
4. Create domain-specific templates.
5. Create one example workflow.
6. Create one sample knowledge graph.
7. Define human review rules.
8. Explain how users should add new knowledge.

## Output

Provide:

- Domain folder structure
- Note types
- Relationship vocabulary
- Templates
- Example notes
- Usage workflow
- Review rules
