# Human Approval Model

Not all knowledge should be auto-updated.

## Approval levels

```text
Level 0: Auto-apply
Level 1: Review recommended
Level 2: Human approval required
Level 3: Expert approval required
```

## Auto-apply examples

- Formatting cleanup
- Link correction
- Tag addition
- Minor glossary note
- Simple example note

## Review recommended

- New concept
- New process
- New example
- Updated map
- Relationship changes

## Human approval required

- Rules
- Important decisions
- Domain definitions
- Policies
- Operational procedures
- Anything that affects real behavior

## Expert approval required

- Legal rules
- Medical rules
- Security rules
- Financial rules
- Institutional policies
- Critical decisions
