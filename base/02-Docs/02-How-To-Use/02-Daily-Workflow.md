# Daily Workflow

Use this daily workflow to keep the vault clean.

## Morning or start of work

1. Check `00-Inbox`.
2. Select raw notes to process.
3. Convert them into structured notes.
4. Add relationships.
5. Update maps.

## During work

Capture raw knowledge quickly.

Do not worry about perfect structure immediately.

Put rough notes into:

```text
00-Inbox
```

## End of day

1. Review new notes.
2. Check broken links.
3. Move finished notes to correct folders.
4. Update `99-Graph/graph.md` if needed.
5. Archive outdated notes.

## Weekly review

Use `40-Reviews` to review:

- Important decisions
- Conflicting notes
- Outdated concepts
- Missing relationships
- Domain-specific improvements
