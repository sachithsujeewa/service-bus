# Manual Use Without Agent

You can use this vault without an AI agent.

## Manual process

```text
1. Add raw note to 00-Inbox
2. Create structured note from template
3. Add YAML metadata
4. Add relationships
5. Update maps
6. Review important notes
```

## Example

Raw note:

```text
Students should understand primary keys before learning foreign keys.
```

Structured relationship:

```markdown
- [[Foreign Key]] --requires--> [[Primary Key]]
```

## Best practice

Keep each note focused on one concept, process, rule, decision, or example.
