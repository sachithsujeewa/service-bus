# What This Vault Is

This vault is a **generic knowledge structure** built using Obsidian-compatible Markdown.

It can be used with the Obsidian app, but it does not depend on Obsidian software.

The real structure is:

- Folders
- Markdown files
- YAML frontmatter
- `[[wiki links]]`
- Tags
- Relationship annotations
- Graph files

## Simple definition

This vault helps you turn raw information into connected knowledge.

```text
Notes become concepts.
Concepts become relationships.
Relationships become a knowledge graph.
The graph supports understanding.
```

## Why use this structure?

Normal notes are often isolated.

Example:

```text
note-1.md
note-2.md
meeting-summary.md
random-idea.md
```

A structured vault turns notes into connected knowledge.

Example:

```text
Concept A --requires--> Concept B
Process X --uses--> Rule Y
Decision D --affects--> Process X
Example E --explains--> Concept A
```

## Who can use it?

This vault can be used by:

- Students
- Researchers
- Product teams
- Software teams
- Business teams
- Trainers
- Consultants
- AI agents
- Knowledge managers

## Main idea

The vault is not customized to one domain.  
It is a reusable structure that can be adapted to many domains.
